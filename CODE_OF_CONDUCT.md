# Code of Conduct

## Our standard

Be respectful, be constructive, assume good intent, and focus on the work.
Harassment, personal attacks, and discriminatory language are not acceptable.

## Scope

This applies to all project spaces — issues, pull requests, discussions, and
any private correspondence relating to the project.

## Enforcement

Report unacceptable behaviour to the repository owner. Reports will be handled
discreetly.

## Attribution

If this project is published under a Microsoft organization, it will adopt the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
