bpm-named-areequal-arguments@1
Changed C# test-method calls spelled Assert.AreEqual with at least two supplied arguments must name every supplied argument using the selected overload's parameter names. For MSTest's usual overload, these include expected: and actual:. Report one finding per method, anchored at its first changed positional call. Unknown syntax or test-method containment is not actionable.
